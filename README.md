# ETBS Scheduled Slider

VK Blocks のスライダーを、管理画面から1枚ずつ差し替えられるようにする WordPress プラグインです。スライドごとに表示開始・表示終了の日時を設定でき、時刻どおりに出し入れします。

- 動きと見た目は VK Blocks（無料版でも可）のスライダーをそのまま使います
- cron を使わず、LiteSpeed Cache の保存期間を次の切り替え時刻に合わせて切り替えます
- 1 つのサイトに複数のスライダーを作れます

開発中です。仕様は [docs/spec.md](docs/spec.md) を参照してください。
