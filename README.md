# ETBS Scheduled Slider

VK Blocks のスライダーを、管理画面から1枚ずつ差し替えられるようにする WordPress プラグインです。スライドごとに表示開始・表示終了の日時を設定でき、時刻どおりに出し入れします。

- 動きと見た目は VK Blocks（無料版でも可）のスライダーをそのまま使います
- cron を使わず、LiteSpeed Cache の保存期間を次の切り替え時刻に合わせて切り替えます
- 1 つのサイトに複数のスライダーを作れます

## 必要なもの

- WordPress 6.3 以上・PHP 7.4 以上
- VK Blocks（無料版または Pro）。無効のときは、スライダーは表示されません
- LiteSpeed Cache は任意です。入っていれば、表示の切り替え時刻に合わせてページの保存期間を短くし、スライドを保存したときに保存済みのページを捨てます

## 使い方

1. 管理画面の「スライダー」→「スライダーを追加」で、スライダーを作ります（ひな形と動きを選びます）
2. 「スライドを追加」で、画像・リンク先・表示開始日時（必須）・表示終了日時を入れて「表示に登録」します
3. 表示したいページに、ブロック「予約スライダー」を置いて、スライダーを選びます

既存の VK Blocks のスライダーから移すときは、WP-CLI の `wp etss import-vk-slider` が使えます（先に `--dry-run` で割り当てを確かめてください）。
